## Обо мне

Совмещаю системный анализ с практической разработкой программного обеспечения.

Мой опыт включает enterprise IT, проектирование технических решений, формализацию процессов и реализацию production-систем.

![Знаете, я и сам своего рода разработчик](./assets/mems.png)

Основные направления:

- системный и интеграционный анализ;
- требования и бизнес-правила;
- проектирование API и контрактов;
- моделирование данных, состояний и процессов;
- поведение систем, ошибки и change impact;
- проектирование решений с учетом реализации.

> Предпочитаю анализ, который можно реализовать: требования, контракты и архитектура должны сохранять смысл при переходе к реальному коду.
